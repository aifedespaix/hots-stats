# Local dev/test environment for the replay ingestion pipeline — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a real backend pipeline test — daemon parser → API ingest → Postgres — run entirely locally, using the real `.StormReplay` files already committed under `debug/`, so a change can be verified end-to-end before `git commit`/`git push` without a human or any OAuth secrets.

**Architecture:** Reuse `docker-compose.dev.yml`'s Postgres container for a second `hots_stats_test` database, bootstrapped by an idempotent script. `apps/api` integration tests call the Hono `ingestRoute` in-process (`.request()`, no server) against that real database. `daemon-python` gets a real-replay corpus test (curated subset by default, full 71-file sweep opt-in) using the actual parser, not synthetic events. A small script bridges the two by dumping real parsed payloads as JSON fixtures apps/api's tests consume.

**Tech Stack:** Bun (`bun:test`, Bun Shell `$`), Drizzle ORM / `postgres` (Postgres client), Hono, Python `pytest`, Docker Compose.

**Spec:** [docs/superpowers/specs/2026-08-31-dev-test-environment-design.md](../specs/2026-08-31-dev-test-environment-design.md)

## Global Constraints

- No CI wiring in this pass — everything here runs locally, on demand (spec §Non-goals).
- No web app / Playwright tests — `apps/web` is untouched.
- No OAuth in tests — the ingest path authenticates via Personal Access Token only. Confirmed during planning: testing `ingestRoute` directly (not the full `index.ts` app) means `apps/api/src/lib/env.ts`'s strict schema (which requires `GOOGLE_CLIENT_ID`, `SESSION_SECRET`, etc.) is never imported, so `.env.test` only needs `DATABASE_URL`.
- Reuse `docker-compose.dev.yml` — no second compose file, no Testcontainers dependency.
- `.env.test` is gitignored (already covered by the repo's existing `.env.*` / `!.env.example` pattern) and generated by `scripts/test-db-up.ts`, never hand-written.
- The curated replay list lives in exactly one place, `daemon-python/tests/corpus.py`, so the corpus test and the fixture-dump script can't drift on which files count as "curated."
- `match_players.hero_id` is a `NOT NULL` foreign key into `heroes` with no auto-create (unlike `maps`, which `ensureMapExists()` creates on the fly) — the test DB bootstrap must run `packages/db`'s `seed.ts`, not just `migrate.ts`.
- Structural invariants only for real-replay assertions (parses cleanly, 10 players, resolved heroes, plausible duration) — no byte-exact "golden stats" comparisons.

```ts
#!/usr/bin/env bun
/**
 * Ensures a local Postgres is up (via docker-compose.dev.yml) and a
 * `hots_stats_test` database exists, migrated and seeded (maps + heroes),
 * writing `.env.test` if it doesn't already exist. Idempotent -- safe to
 * run before every `bun run test:api` invocation, including on a fresh
 * checkout. See docs/superpowers/specs/2026-08-31-dev-test-environment-design.md.
 */
import { existsSync, writeFileSync } from "node:fs";
import { join } from "node:path";
import { $ } from "bun";

const TEST_DB_NAME = "hots_stats_test";
const PG_USER = process.env.POSTGRES_USER ?? "postgres";
const PG_PASSWORD = process.env.POSTGRES_PASSWORD ?? "postgres";
const TEST_DATABASE_URL = `postgres://${PG_USER}:${PG_PASSWORD}@localhost:5432/${TEST_DB_NAME}`;
const ENV_TEST_PATH = join(import.meta.dir, "..", ".env.test");

async function ensureDockerUp(): Promise<void> {
  await $`docker compose -f docker-compose.dev.yml up -d`;

  for (let attempt = 1; attempt <= 20; attempt++) {
    const result = await $`docker compose -f docker-compose.dev.yml exec -T postgres pg_isready -U ${PG_USER}`
      .nothrow()
      .quiet();
    if (result.exitCode === 0) return;
    await Bun.sleep(500);
  }
  throw new Error("Postgres did not become ready within 10s of `docker compose up`.");
}

async function ensureTestDatabase(): Promise<void> {
  const postgres = (await import("postgres")).default;
  const maint = postgres(`postgres://${PG_USER}:${PG_PASSWORD}@localhost:5432/postgres`, { max: 1 });
  try {
    const [{ exists }] =
      await maint`SELECT EXISTS (SELECT FROM pg_database WHERE datname = ${TEST_DB_NAME}) AS exists`;
    if (!exists) {
      await maint.unsafe(`CREATE DATABASE ${TEST_DB_NAME}`);
      console.log(`Created database ${TEST_DB_NAME}`);
    }
  } finally {
    await maint.end();
  }
}

function ensureEnvTestFile(): void {
  if (existsSync(ENV_TEST_PATH)) return;
  writeFileSync(
    ENV_TEST_PATH,
    "# Generated by scripts/test-db-up.ts -- local only, gitignored (see .gitignore's .env.* pattern).\n" +
      `DATABASE_URL=${TEST_DATABASE_URL}\n`,
  );
  console.log(`Wrote ${ENV_TEST_PATH}`);
}

async function migrateAndSeed(): Promise<void> {
  const env = { ...process.env, DATABASE_URL: TEST_DATABASE_URL };
  await $`bun run packages/db/src/migrate.ts`.env(env);
  await $`bun run packages/db/src/seed.ts`.env(env);
}

await ensureDockerUp();
await ensureTestDatabase();
ensureEnvTestFile();
await migrateAndSeed();
console.log(`Test database ready: ${TEST_DATABASE_URL}`);
```

- [ ] **Step 3: Write `daemon-python/scripts/dump_fixture_payloads.py`**

```python
"""Regenerates apps/api's replay-fixture JSON from real `.StormReplay`
files (the "ok" entries in tests/corpus.py's CURATED_REPLAYS) using the
daemon's own `parser.parse_replay` -- not a reimplementation. Run by hand
whenever `ReplayPayload`'s shape changes and the fixtures need refreshing
(same maintenance model as diagnose_hero_mapping.py and this directory's
other scripts) -- the resulting git diff shows exactly what changed in the
payload shape.

Usage (from `daemon-python/`, deps installed via `pip install -e ".[dev]"`):
    python scripts/dump_fixture_payloads.py
"""

from __future__ import annotations

import json
import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent.parent))

from src.parser import parse_replay  # noqa: E402
from tests.corpus import CURATED_REPLAYS, REPLAY_DIR  # noqa: E402

FIXTURES_DIR = (
    Path(__file__).resolve().parent.parent.parent / "apps" / "api" / "src" / "test-support" / "fixtures" / "replays"
)


def main() -> None:
    FIXTURES_DIR.mkdir(parents=True, exist_ok=True)
    written: list[str] = []
    for filename, expected_outcome in CURATED_REPLAYS:
        if expected_outcome != "ok":
            continue
        payload = parse_replay(REPLAY_DIR / filename)
        # Mirrors ingestion.py's own pop -- `_pendingSpatialSample` is an
        # internal signal for the daemon's own sync loop (POST
        # /spatial/samples), never part of the wire body POSTed to /ingest.
        payload.pop("_pendingSpatialSample", None)
        out_path = FIXTURES_DIR / f"{payload['map']}.json"
        out_path.write_text(json.dumps(payload, indent=2, ensure_ascii=False) + "\n", encoding="utf-8")
        written.append(out_path.name)

    print(f"wrote {len(written)} fixture(s) to {FIXTURES_DIR}: {written}")


if __name__ == "__main__":
    main()
```

```python
"""Real-replay regression tests for the parser, using actual
`.StormReplay` files committed under `debug/` (see tests/corpus.py)
instead of synthetic protocol events -- catches drift between the parser
and the real game client's output that hand-built fixtures can't.
Structural invariants only (no crash, right player count, resolved
heroes), not exact stat values -- see
docs/superpowers/specs/2026-08-31-dev-test-environment-design.md's
Non-goals for why.
"""

from __future__ import annotations

import pytest

from src.parser import ReplayParseError, ReplaySkipped, parse_replay
from tests.corpus import CURATED_REPLAYS, REPLAY_DIR


def _assert_structurally_sane(payload: dict) -> None:
    assert payload["m_baseBuild"] > 0
    assert payload["durationSeconds"] > 0
    assert len(payload["players"]) == 10
    for player in payload["players"]:
        assert player["heroId"]
        assert player["battletag"]


@pytest.mark.parametrize("filename,expected_outcome", CURATED_REPLAYS)
def test_curated_replay_matches_expected_outcome(filename: str, expected_outcome: str) -> None:
    path = REPLAY_DIR / filename
    assert path.exists(), f"curated fixture missing from debug/: {filename}"

    if expected_outcome == "ok":
        payload = parse_replay(path)
        _assert_structurally_sane(payload)
    elif expected_outcome == "skipped":
        with pytest.raises(ReplaySkipped):
            parse_replay(path)
    elif expected_outcome == "corrupt_score":
        with pytest.raises(ReplayParseError, match="all-zero"):
            parse_replay(path)
    else:
        pytest.fail(f"unknown expected_outcome in corpus.py: {expected_outcome}")


@pytest.mark.full_corpus
def test_full_corpus_has_no_unexpected_errors() -> None:
    """Sweeps every `.StormReplay` file directly under `debug/` -- slow,
    excluded from the default run (see pyproject.toml's addopts). Run by
    hand after a parser change: `pytest -m full_corpus`.
    """
    files = sorted(REPLAY_DIR.glob("*.StormReplay"))
    assert files, f"no .StormReplay files found in {REPLAY_DIR}"

    unexpected: list[tuple[str, str]] = []
    for f in files:
        try:
            payload = parse_replay(f)
            _assert_structurally_sane(payload)
        except ReplaySkipped:
            pass  # intentional skip (AI player / incomplete game) -- fine
        except ReplayParseError as e:
            if "all-zero" not in str(e):
                unexpected.append((f.name, str(e)))
        except Exception as e:  # noqa: BLE001 -- any other exception here
            # IS the unexpected-error signal this test exists to catch.
            unexpected.append((f.name, f"{type(e).__name__}: {e}"))

    assert not unexpected, f"{len(unexpected)} replay(s) failed unexpectedly: {unexpected}"
```

import { db, knownBuilds, personalAccessTokens, users } from "@hots-stats/db";
import { sql } from "drizzle-orm";
import { generatePersonalAccessToken, hashToken } from "../lib/tokens";

// Every table `resetDb()` clears between tests -- everything except
// `maps`/`heroes`, which stay seeded by `packages/db`'s seed script (run
// once against the test DB by `bun run test:db:up`) since ingest depends
// on those rows already existing: `match_players.hero_id` is a NOT NULL
// FK with no auto-create, unlike `maps` (see `ensureMapExists()`).
const RESETTABLE_TABLES = [
  "users",
  "personal_access_tokens",
  "matches",
  "match_players",
  "talent_picks",
  "match_deaths",
  "match_level_snapshots",
  "friendships",
  "raw_replays_quarantine",
  "known_builds",
  "draft_pseudo_preferences",
  "daemon_ingest_errors",
  "player_annotations",
  "map_calibrations",
  "raw_map_samples",
  "match_spatial_grids",
  "hero_map_player_spatial_rollup",
  "hero_map_global_spatial_rollup",
  "match_hero_trajectories",
  "match_structure_events",
] as const;

/** Truncates every table except `maps`/`heroes` (reference data seeded once). Call in `beforeEach` so tests don't leak state into each other. */
export async function resetDb(): Promise<void> {
  await db.execute(sql.raw(`TRUNCATE TABLE ${RESETTABLE_TABLES.join(", ")} RESTART IDENTITY CASCADE`));
}

export type SeededUser = { userId: string; rawToken: string };

/** Inserts a user + a working Personal Access Token, returning the raw token for `Authorization: Bearer <rawToken>`. */
export async function seedUserWithToken(): Promise<SeededUser> {
  const [user] = await db
    .insert(users)
    .values({ displayName: "Test User", battletag: "TestUser#1234" })
    .returning({ id: users.id });

  const rawToken = generatePersonalAccessToken();
  await db.insert(personalAccessTokens).values({
    userId: user.id,
    name: "test token",
    tokenHash: hashToken(rawToken),
  });

  return { userId: user.id, rawToken };
}

/** Marks `baseBuild` as verified-compatible with `DefaultAdapter`, matching what `bun run check-build` would do -- required before POST /ingest processes (rather than quarantines) a payload carrying that build. */
export async function seedKnownBuild(baseBuild: number): Promise<void> {
  await db.insert(knownBuilds).values({ baseBuild }).onConflictDoNothing();
}
